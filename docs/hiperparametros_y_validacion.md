# Hiperparámetros, cribado y validación

Las [recetas y reglas](../config/benchmark_regresion.json) y la [regla de recomendación](../config/lectura_benchmark_regresion.json) se fijaron antes de obtener la evaluación de este sprint. La selección se orienta a error absoluto sobre la primera falla, no a la precisión de una clasificación. El MAE externo se calcula una vez reunida la predicción reservada de cada caso. El sesgo se define como predicho menos observado: un signo positivo indica sobreestimación.

**Secuencia por reserva externa.** Se separa el grupo antes de aprender cualquier transformación. En el entrenamiento exterior se forman 5 particiones internas por configuración nominal; en la prueba de transferencia se retira cada uno de los 2 niveles restantes. El ajuste de imputación, filtro de constantes, escalamiento cuando corresponde y selección de base OLS se repite para cada entrenamiento correspondiente. No se usa el nivel reservado para *early stopping*, escoger familias, cambiar k ni decidir el número de árboles.

1. **Cribado.** Evaluar las cinco recetas ajustables con los mismos grupos internos. Para cada uno de los dos puestos, incluir las familias a no más de 1 N del menor MAE interno restante. Preferir menor MAD del MAE por grupo; después, menor MAE y el orden predefinido de complejidad. La MAD es la mediana de las desviaciones absolutas respecto a la mediana sin factor de normalización. Un newton es una banda operativa declarada; no se conoce una tolerancia mecánica validada.
2. **Búsqueda aleatoria discreta.** Solo las dos candidatas reciben ocho recetas cada una: la inicial y siete configuraciones distintas muestreadas sin reemplazo. Los dibujos se fijan antes del ajuste (semilla de búsqueda 20261106). Dentro de cada familia escoger menor MAE OOF interno reunido por espécimen; ante igualdad numérica, usar la dispersión y el orden congelado. Árboles y boosting tienen semillas fijas y un hilo por estimador.
3. **Evaluación.** Reajustar con el entrenamiento exterior y predecir el grupo reservado. Los dos rangos corresponden al orden de cribado previo al tuning. Un tercer procedimiento, el selector, usa el mejor de los dos ajustados según su validación **interna**. Los rangos y el selector comparten trabajo: no son tres búsquedas independientes. No se suman sus tiempos como si lo fueran.
4. **Receta para uso posterior.** Repetir el cribado y selección sobre toda la campaña, agrupando validaciones según el objetivo. Se separan la receta obtenida con todos los datos y las predicciones externas de los procedimientos. Si una familia apareció solo en algunos pliegues, su error en esos pliegues no es su MAE sobre toda la campaña.

**Estabilidad, coste y alcance.** Se publican tiempos de ajuste y predicción por separado de la búsqueda. Las diferencias de milisegundos dependen del equipo; no intervienen como desempate numérico. Las DE y los IQR externos se expresan en N, no son intervalos de confianza. El error de entrenamiento sirve para examinar discrepancias con el error reservado: una brecha puede reflejar sobreajuste, correlación entre predictores o cambio arquitectónico; no identifica por sí sola el motivo.

**Adopción.** Dentro de una banda descriptiva de 1 N respecto al menor MAE de las seis recetas fijas se favorece parsimonia según el [orden declarado](../config/lectura_benchmark_regresion.json). Adoptar el procedimiento de tuning sobre esa receta exige simultáneamente ≥1 N de mejora, no empeorar RMSE, reducir MAE en más de la mitad de los grupos nominales y mantener el signo de la ventaja al omitir del agregado cada grupo por turno. Se repite esa comparación con la media por nivel para decidir si hace falta un modelo más complejo en niveles conocidos. Omitir errores del agregado **no reentrena** el modelo. Las reglas producen una recomendación exploratoria, no una prueba de superioridad en una población externa.
